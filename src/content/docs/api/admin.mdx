All endpoints on this page require the **Admin** role.

## System Status

```
GET /api/admin/status
```

**Auth:** Session Cookie (Admin)

Returns a system overview including user count, measurements, worker status, integration status, and version.

```bash
curl -s https://your-instance.example.com/api/admin/status \
  -H "Cookie: healthlog_session=abc123"
```

**Response:**

```json
{
  "data": {
    "version": "1.12.10",
    "users": 3,
    "measurements": 1842,
    "medications": 7,
    "moodEntries": 156,
    "worker": { "status": "RUNNING", "pendingJobs": 0 },
    "integrations": {
      "withings": { "connected": true },
      "telegram": { "configured": true },
      "glitchtip": { "configured": true }
    }
  },
  "error": null
}
```

## App Settings

```
GET /api/admin/settings
PUT /api/admin/settings
```

**Auth:** Session Cookie (Admin)

Manages global application settings.

### Assistant Flags

```
GET /api/admin/settings/assistant-flags
PUT /api/admin/settings/assistant-flags
```

Toggles the AI assistant / Coach feature flags for the deployment.

## AI Configuration

```
GET /api/admin/ai-settings    — Read admin-shared AI provider config
PUT /api/admin/ai-settings    — Update admin-shared AI provider config
GET /api/admin/ai-quality     — AI insight quality metrics
```

**Auth:** Session Cookie (Admin)

Manages the operator's shared AI key (the last-ditch fallback in the
[provider chain](/settings/ai-providers/)) and surfaces quality telemetry.

## User Management

### List All Users

```
GET /api/admin/users
```

### Single User

```
GET /api/admin/users/[id]
```

### Delete User

```
DELETE /api/admin/users/[id]
```

### Reset Password

```
POST /api/admin/users/[id]/reset-password
```

Generates a temporary password for the user.

### Force Logout

```
POST /api/admin/users/[id]/force-logout
```

Invalidates all of the user's sessions and bearer tokens immediately.

```bash
curl -s -X POST https://your-instance.example.com/api/admin/users/clx.../reset-password \
  -H "Cookie: healthlog_session=abc123"
```

**Response:**

```json
{
  "data": {
    "temporaryPassword": "xK9m!pQ2..."
  },
  "error": null
}
```

## Audit Log

```
GET /api/admin/audit-log
GET /api/admin/audit-log/actions
```

**Auth:** Session Cookie (Admin)

Returns the audit log (login attempts, changes, admin actions). The `actions`
endpoint returns the distinct action types for filtering.

## Feedback & Bug Reports

```
GET    /api/admin/feedback                    — List submitted feedback / bug reports
PATCH  /api/admin/feedback/[id]               — Update a report's status
DELETE /api/admin/feedback/[id]               — Delete a report
POST   /api/admin/feedback/[id]/github        — File the report as a GitHub issue
```

**Auth:** Session Cookie (Admin)

## Test Notifications

```
POST /api/admin/notifications/test
```

**Auth:** Session Cookie (Admin)

Sends a test notification through all configured channels.

### Reminder Check

```
POST /api/admin/notifications/reminder-check
```

**Auth:** Session Cookie (Admin)

Triggers a manual check for due medication reminders.

### Notification Diagnostic

```
GET /api/admin/notifications/diagnostic
```

**Auth:** Session Cookie (Admin)

Reports per-channel notification configuration health (Telegram / ntfy / Web
Push / APNs) for troubleshooting delivery.
