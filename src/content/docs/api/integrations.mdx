## Withings

Integration with Withings devices (scales, blood pressure monitors) for automatic data import.

### Connect

```
GET /api/withings/connect
```

**Auth:** Session Cookie

Redirects to the Withings OAuth authorization flow.

### OAuth Callback

```
GET /api/withings/callback
```

Processes the OAuth callback from Withings and stores the credentials.

### Connection Status

```
GET /api/withings/status
```

**Auth:** Session Cookie

```json
{
  "data": {
    "connected": true,
    "lastSync": "2026-03-08T06:00:00.000Z",
    "deviceCount": 2
  },
  "error": null
}
```

### Sync

```
POST /api/withings/sync
```

**Auth:** Session Cookie

Triggers a manual sync of Withings data.

```bash
curl -s -X POST https://your-instance.example.com/api/withings/sync \
  -H "Cookie: healthlog_session=abc123"
```

### Disconnect

```
POST /api/withings/disconnect
```

**Auth:** Session Cookie

### Manage Credentials

```
GET /api/withings/credentials
PUT /api/withings/credentials
```

**Auth:** Session Cookie

Manages Withings API credentials (Client ID, Client Secret).

### Webhook

```
POST /api/withings/webhook
```

**Auth:** HMAC signature

Receives real-time notifications from Withings when new measurements are available. The request is verified via HMAC signature.

## WHOOP

OAuth 2.0 integration with WHOOP recovery straps (bring-your-own-keys). The route set mirrors Withings.

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `GET`  | `/api/whoop/connect` | Session Cookie | Redirect to the WHOOP OAuth authorization flow |
| `GET`  | `/api/whoop/callback` | — | OAuth callback; stores the connection |
| `GET`  | `/api/whoop/status` | Session Cookie | Connection state |
| `POST` | `/api/whoop/sync` | Session Cookie | Manual sync — incremental by default, full history with `{ "fullSync": true }` |
| `POST` | `/api/whoop/disconnect` | Session Cookie | Remove the connection |
| `GET` / `PUT` | `/api/whoop/credentials` | Session Cookie | Read / set the per-user Client ID + Client Secret |
| `POST` | `/api/integrations/whoop/test` | Session Cookie | Probe a saved connection |
| `POST` | `/api/integrations/whoop/resume` | Session Cookie | Resume after a revoked grant |
| `POST` | `/api/whoop/webhook/{token}` | HMAC signature | Near-real-time data notifications |

## Google Health / Fitbit (experimental)

OAuth 2.0 integration with Fitbit and Pixel data over Google's Health API (bring-your-own-keys). The route set mirrors WHOOP.

:::caution
Experimental — Google's Health API is young and several per-type value fields are not yet fully published, so some data types may import nothing until the wire mapping is verified against a live account.
:::

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `GET`  | `/api/fitbit/connect` | Session Cookie | Redirect to the Google OAuth consent flow |
| `GET`  | `/api/fitbit/callback` | — | OAuth callback; stores the connection |
| `GET`  | `/api/fitbit/status` | Session Cookie | Connection state |
| `POST` | `/api/fitbit/sync` | Session Cookie | Manual sync — incremental by default, full history with `{ "fullSync": true }` |
| `POST` | `/api/fitbit/disconnect` | Session Cookie | Remove the connection |
| `GET` / `PUT` | `/api/fitbit/credentials` | Session Cookie | Read / set the per-user Client ID + Client Secret |
| `POST` | `/api/integrations/fitbit/test` | Session Cookie | Probe a saved connection |
| `POST` | `/api/integrations/fitbit/resume` | Session Cookie | Resume after a revoked grant |

Imported data lands as `Measurement` rows with `source = FITBIT` (and workouts on the `Workout` table). See [`src/lib/fitbit/mapping.md`](https://github.com/MBombeck/HealthLog/blob/main/src/lib/fitbit/mapping.md) for the data-type → measurement table.

## MoodLog

Integration with the MoodLog app for importing mood data.

### Status

```
GET /api/integrations/moodlog/status
```

**Auth:** Session Cookie

```json
{
  "data": {
    "connected": true,
    "lastSync": "2026-03-08T19:30:00.000Z",
    "entriesImported": 47
  },
  "error": null
}
```

### Sync

```
POST /api/integrations/moodlog/sync
```

**Auth:** Session Cookie

Triggers a manual import of MoodLog data.

### Webhook

```
POST /api/integrations/moodlog/webhook
```

**Auth:** HMAC signature

Receives real-time notifications from MoodLog when new entries are created. The request is verified via HMAC signature.
