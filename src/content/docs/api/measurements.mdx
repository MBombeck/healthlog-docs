## Measurement Types

`type` is one of the `MeasurementType` enum values below. This is the canonical
machine list — it mirrors the server's Prisma enum exactly, and the
[Health Metrics feature page](/features/health-metrics/) links here for the
authoritative set. Values stored canonically in SI; some HealthKit/Withings
identifiers are re-scaled on ingest (noted per row). The unit shown is the
**stored canonical unit** — the metric/imperial display preference may render it
differently.

### Device-flagged events

These rows are not continuous measurements — each records one discrete on-device
notification (`value` is always `1`); the device's verdict/severity rides in a
separate classification column. HealthLog never re-derives or re-classifies the
underlying signal; it surfaces only what the device's certified algorithm
emitted. **Awareness/screening signals only — never a HealthLog diagnosis.**

| Type | Description | Unit |
|------|-------------|------|
| `IRREGULAR_RHYTHM_NOTIFICATION` | Possible irregular rhythm (HealthKit / ScanWatch AFib screening) | event |
| `HIGH_HEART_RATE_EVENT` | Sustained high heart rate while inactive | event |
| `LOW_HEART_RATE_EVENT` | Sustained low heart rate | event |
| `WALKING_STEADINESS_EVENT` | Low / very-low walking steadiness | event |
| `BREATHING_DISTURBANCE_EVENT` | Elevated breathing-disturbance / possible sleep-apnea signal | event |

### Computed & device scores

Server-derived wellness scores (`COMPUTED` source) and WHOOP-native scores. These
are descriptive, not clinical, and never appear in the doctor-report PDF.
`STRESS_SCORE` / `STRAIN_SCORE` are reserved — no engine computes them yet.

| Type | Description | Unit |
|------|-------------|------|
| `RECOVERY_SCORE` | Daily recovery / readiness proxy (COMPUTED or WHOOP) | score |
| `STRESS_SCORE` | Reserved — physiological stress | score |
| `STRAIN_SCORE` | Reserved — cardiovascular strain (TRIMP proxy) | score |
| `DAY_STRAIN` | Day cardiovascular load, 0–21 (WHOOP) | score |
| `WORKOUT_STRAIN` | Per-workout strain, 0–21 (WHOOP) | score |

For `BLOOD_GLUCOSE` measurements, you must also send a `glucoseContext`
field with one of `FASTING`, `POSTPRANDIAL`, `RANDOM`, or `BEDTIME`. Other
types must omit the field. See the [Health Metrics feature
page](/features/health-metrics/) for the clinical framing, body composition,
and the Withings auto-sync flow.

### Units & display preference

Measurements are stored **canonically in SI** — kilograms, metres, metres per
second, degrees Celsius — regardless of where they came from or how they are
shown. A per-user **metric/imperial display preference** (Settings → Display,
also surfaced as `unitPreference` on [`/api/auth/me`](/api/authentication/#current-user))
drives a render-time transform only: walking speed is shown in km/h and distance
in km, and the imperial setting converts at display time. The stored and
**exported** values stay SI, so the FHIR R4 export's [UCUM](https://ucum.org/)
units are always canonical.

## List Measurements

```
GET /api/measurements
```

**Auth:** Session Cookie or Bearer Token

**Query Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | string | Filter by measurement type |
| `from` | ISO 8601 | Start date |
| `to` | ISO 8601 | End date |
| `limit` | number | Max results (default: 20) |
| `offset` | number | Offset for pagination |
| `sortBy` | string | Sort field (e.g. `measuredAt`) |
| `sortDir` | `asc` / `desc` | Sort direction |

```bash
curl -s "https://your-instance.example.com/api/measurements?type=WEIGHT&limit=5&sortDir=desc" \
  -H "Cookie: healthlog_session=abc123"
```

**Response:**

```json
{
  "data": [
    {
      "id": "clx...",
      "type": "WEIGHT",
      "value": 81.5,
      "measuredAt": "2026-03-08T07:30:00.000Z",
      "notes": null,
      "createdAt": "2026-03-08T07:31:12.000Z"
    }
  ],
  "error": null,
  "meta": { "total": 142, "limit": 5, "offset": 0 }
}
```

## Create Measurement

```
POST /api/measurements
```

**Auth:** Session Cookie or Bearer Token

Supports both single values and batch creation (array).

### Single Measurement

```json
{
  "type": "WEIGHT",
  "value": 81.5,
  "measuredAt": "2026-03-08T07:30:00.000Z",
  "notes": "Measured fasting"
}
```

### Blood Pressure (Batch)

A blood pressure reading consists of two related measurements:

```bash
curl -s https://your-instance.example.com/api/measurements \
  -H "Content-Type: application/json" \
  -H "Cookie: healthlog_session=abc123" \
  -d '[
    {
      "type": "BLOOD_PRESSURE_SYS",
      "value": 125,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    },
    {
      "type": "BLOOD_PRESSURE_DIA",
      "value": 82,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    },
    {
      "type": "PULSE",
      "value": 68,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    }
  ]'
```

**Response** `201`:

```json
{
  "data": [
    { "id": "clx1...", "type": "BLOOD_PRESSURE_SYS", "value": 125, "measuredAt": "2026-03-08T08:00:00.000Z" },
    { "id": "clx2...", "type": "BLOOD_PRESSURE_DIA", "value": 82, "measuredAt": "2026-03-08T08:00:00.000Z" },
    { "id": "clx3...", "type": "PULSE", "value": 68, "measuredAt": "2026-03-08T08:00:00.000Z" }
  ],
  "error": null
}
```

## Single Measurement

### Retrieve

```
GET /api/measurements/[id]
```

### Update

```
PUT /api/measurements/[id]
```

```json
{
  "value": 82.0,
  "notes": "Corrected"
}
```

### Delete

```
DELETE /api/measurements/[id]
```

**Auth:** Session Cookie or Bearer Token. Users can only modify their own measurements.

## Related Endpoints

| Endpoint | Purpose |
|----------|---------|
| `GET /api/measurements/series?kind=&days=` | Time-series adapter: maps a camelCase `kind` to the canonical `MeasurementType`(s) and returns chart-ready `{ points, stats }`. `kind=bloodPressure` pairs systolic + diastolic. |
| `POST /api/measurements/batch` | Idempotent batch ingest used by the iOS HealthKit drain. See [Native Clients](/api/native-clients/). |
| `DELETE /api/measurements/by-external-ids` | Deletion reconciliation for HealthKit samples removed on-device. See [Native Clients](/api/native-clients/). |
