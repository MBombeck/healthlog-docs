## Measurement Types

| Type | Description | Unit |
|------|-------------|------|
| `WEIGHT` | Body weight | kg |
| `BLOOD_PRESSURE_SYS` | Systolic blood pressure | mmHg |
| `BLOOD_PRESSURE_DIA` | Diastolic blood pressure | mmHg |
| `PULSE` | Pulse / heart rate | bpm |
| `BODY_FAT` | Body fat percentage | % |
| `BLOOD_GLUCOSE` | Blood glucose (requires `glucoseContext`) | mg/dL |
| `TOTAL_BODY_WATER` | Total body water content (Withings type 77) | kg |
| `BONE_MASS` | Bone mineral content / DEXA-equivalent (Withings type 88) | kg |
| `OXYGEN_SATURATION` | Pulse oximetry / SpO₂ (Withings ScanWatch type 54, HealthKit, Health Connect) | % |
| `SLEEP_DURATION` | Sleep duration | hours |
| `ACTIVITY_STEPS` | Steps | steps |
| `ACTIVE_ENERGY_BURNED` | Active energy | kcal |
| `WALKING_RUNNING_DISTANCE` | Walking + running distance | km |
| `FLIGHTS_CLIMBED` | Flights of stairs climbed | flights |
| `RESTING_HEART_RATE` | Resting heart rate | bpm |
| `WALKING_HEART_RATE_AVERAGE` | Average walking heart rate | bpm |
| `HEART_RATE_VARIABILITY` | Heart-rate variability (SDNN) | ms |
| `VO2_MAX` | Cardiorespiratory fitness | mL/kg·min |
| `RESPIRATORY_RATE` | Respiratory rate | breaths/min |
| `BODY_TEMPERATURE` | Body temperature | °C |
| `SKIN_TEMPERATURE` | Wrist skin temperature | °C |
| `BODY_MASS_INDEX` | Body-mass index | kg/m² |
| `LEAN_BODY_MASS` | Lean body mass | kg |
| `FAT_FREE_MASS` | Fat-free mass | kg |
| `FAT_MASS` | Fat mass | kg |
| `MUSCLE_MASS` | Muscle mass | kg |
| `VISCERAL_FAT` | Visceral fat | rating |
| `PULSE_WAVE_VELOCITY` | Pulse-wave velocity (arterial stiffness) | m/s |
| `VASCULAR_AGE` | Estimated vascular age | years |
| `WALKING_SPEED` | Walking speed | m/s (displayed km/h) |
| `WALKING_STEP_LENGTH` | Walking step length | cm |
| `WALKING_ASYMMETRY` | Walking asymmetry | % |
| `WALKING_DOUBLE_SUPPORT` | Walking double-support time | % |
| `WALKING_STEADINESS` | Walking steadiness | % |
| `AUDIO_EXPOSURE_ENV` | Environmental audio exposure | dB |
| `AUDIO_EXPOSURE_HEADPHONE` | Headphone audio exposure | dB |
| `AUDIO_EXPOSURE_EVENT` | Audio-exposure event | count |
| `TIME_IN_DAYLIGHT` | Time in daylight | minutes |

For `BLOOD_GLUCOSE` measurements, you must also send a `glucoseContext`
field with one of `FASTING`, `POSTPRANDIAL`, `RANDOM`, or `BEDTIME`. Other
types must omit the field. See the [Health Metrics feature
page](/features/health-metrics/) for the full catalogue, body composition,
and the Withings auto-sync flow.

### Units & display preference

Measurements are stored **canonically in SI** — kilograms, metres, metres per
second, degrees Celsius — regardless of where they came from or how they are
shown. A per-user **metric/imperial display preference** (Settings → Display,
also surfaced as `unitPreference` on [`/api/auth/me`](/api/authentication/#current-user))
drives a render-time transform only: walking speed is shown in km/h and distance
in km, and the imperial setting converts at display time. The stored and
**exported** values stay SI, so the FHIR R4 export's [UCUM](https://ucum.org/)
units are always canonical.

## List Measurements

```
GET /api/measurements
```

**Auth:** Session Cookie or Bearer Token

**Query Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `type` | string | Filter by measurement type |
| `from` | ISO 8601 | Start date |
| `to` | ISO 8601 | End date |
| `limit` | number | Max results (default: 20) |
| `offset` | number | Offset for pagination |
| `sortBy` | string | Sort field (e.g. `measuredAt`) |
| `sortDir` | `asc` / `desc` | Sort direction |

```bash
curl -s "https://your-instance.example.com/api/measurements?type=WEIGHT&limit=5&sortDir=desc" \
  -H "Cookie: healthlog_session=abc123"
```

**Response:**

```json
{
  "data": [
    {
      "id": "clx...",
      "type": "WEIGHT",
      "value": 81.5,
      "measuredAt": "2026-03-08T07:30:00.000Z",
      "notes": null,
      "createdAt": "2026-03-08T07:31:12.000Z"
    }
  ],
  "error": null,
  "meta": { "total": 142, "limit": 5, "offset": 0 }
}
```

## Create Measurement

```
POST /api/measurements
```

**Auth:** Session Cookie or Bearer Token

Supports both single values and batch creation (array).

### Single Measurement

```json
{
  "type": "WEIGHT",
  "value": 81.5,
  "measuredAt": "2026-03-08T07:30:00.000Z",
  "notes": "Measured fasting"
}
```

### Blood Pressure (Batch)

A blood pressure reading consists of two related measurements:

```bash
curl -s https://your-instance.example.com/api/measurements \
  -H "Content-Type: application/json" \
  -H "Cookie: healthlog_session=abc123" \
  -d '[
    {
      "type": "BLOOD_PRESSURE_SYS",
      "value": 125,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    },
    {
      "type": "BLOOD_PRESSURE_DIA",
      "value": 82,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    },
    {
      "type": "PULSE",
      "value": 68,
      "measuredAt": "2026-03-08T08:00:00.000Z"
    }
  ]'
```

**Response** `201`:

```json
{
  "data": [
    { "id": "clx1...", "type": "BLOOD_PRESSURE_SYS", "value": 125, "measuredAt": "2026-03-08T08:00:00.000Z" },
    { "id": "clx2...", "type": "BLOOD_PRESSURE_DIA", "value": 82, "measuredAt": "2026-03-08T08:00:00.000Z" },
    { "id": "clx3...", "type": "PULSE", "value": 68, "measuredAt": "2026-03-08T08:00:00.000Z" }
  ],
  "error": null
}
```

## Single Measurement

### Retrieve

```
GET /api/measurements/[id]
```

### Update

```
PUT /api/measurements/[id]
```

```json
{
  "value": 82.0,
  "notes": "Corrected"
}
```

### Delete

```
DELETE /api/measurements/[id]
```

**Auth:** Session Cookie or Bearer Token. Users can only modify their own measurements.
