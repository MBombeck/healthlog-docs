HealthLog offers AI-powered analysis of your health data. As of v1.2 you can pick the provider that fits your privacy and budget profile — there is no longer a single hard-coded vendor.

## Providers

Configure a provider per user under **Settings > AI**:

| Provider | Model examples | Notes |
|----------|---------------|-------|
| **OpenAI** | gpt-4o-mini, gpt-4o | Direct API key (BYOK) or via the admin-shared key |
| **Anthropic Claude** | claude-3-5-haiku, claude-3-5-sonnet | BYOK |
| **Local / OpenAI-compatible** | Ollama, LM Studio, vLLM, LiteLLM, etc. | Custom base URL + optional API key — your data never leaves your network |

Selection is per user. Switching providers does not invalidate cached insights, but the next regeneration will use the new provider.

## Setup

Pick a provider, paste the API key (and base URL for local endpoints), and pick a model. The key and URL are stored AES-256-GCM encrypted in the database.

:::note
Without any provider configured, AI Insights are disabled. All other HealthLog features remain fully functional, and the dashboard simply hides the AI cards.
:::

## Privacy by Provider

- **Local endpoint** — Glucose, BP, weight, mood, and medication data stay on your network. Best fit for fully self-hosted setups.
- **OpenAI / Anthropic** — Data leaves your server only when you explicitly enable AI insights. Choose Aggregated mode to send only summary statistics.
- **Admin shared key** — When an admin configures a global key, users without their own key can opt in. Each request is attributed to the user for audit purposes.

## Privacy Modes

Users choose what data is sent to OpenAI:

| Mode | Description |
|------|------------|
| **Aggregated** | Only statistical summaries (average, min, max, trend) |
| **Raw** | Actual readings with timestamps |

:::caution
In Raw mode, real health data is sent to the OpenAI API. HealthLog never sends data to third parties unless the user has explicitly configured the OpenAI integration.
:::

## Insight Categories

HealthLog generates insights across seven categories:

1. **General** -- Overall health trends
2. **Blood Pressure** -- Trend analysis, classification, recommendations
3. **Weight** -- Trend analysis, BMI development
4. **Heart Rate** -- Resting heart rate trends, anomalies
5. **BMI** -- Long-term development, target range
6. **Medication Compliance** -- Adherence analysis, patterns
7. **Mood** -- Mood trends and correlations (when MoodLog integration is active)

## Correlation Analysis

The AI identifies relationships between different metrics:

- Weight and blood pressure
- Mood and blood pressure (when MoodLog integration is active)
- Mood and weight
- Mood and heart rate
- Blood pressure and medication compliance

## Caching and Generation

- **Cache duration**: 24 hours per insight
- **Automatic generation**: Nightly between 02:00 and 02:30 via pg-boss job
- **Manual generation**: Available anytime from the dashboard (invalidates the cache)

```
Schedule: 02:00-02:30 UTC (pg-boss cron)
Cache TTL: 24 hours
Model: configured per user
```

## Locale-Aware Prompts

Prompts and responses run in the user's selected locale. A German user gets German recommendations; an English user gets English. Numbers, dates, and units (mg/dL vs mmol/L, kg, mmHg) are formatted by `useFormatters()` before being injected into the prompt — the model never has to translate or convert.

:::tip
The nightly auto-generation ensures that fresh insights are ready when you open the app in the morning, with no waiting required.
:::
