HealthLog can generate a comprehensive PDF report designed for sharing with healthcare providers. The report follows European medical formatting conventions and uses German medical terminology.

## Generation

The PDF is generated entirely **client-side** using jsPDF. No data is sent to a server during generation.

- Open **Settings → Export** and click the **Generate Report** button on the doctor-report card.
- A dialog opens where you pick the date range and, optionally, the practice name.
- The PDF is downloaded directly to the device.

### Date Range

Before the PDF is generated, a dialog asks for the period you want covered. Three presets — **Last 90 days**, **Last 6 months**, **Last 12 months** — match the windows physicians ask for most often. You can also enter custom start and end dates by hand. The maximum span is 2 years; the default is the last 90 days.

### Practice / Clinic Name

The dialog also has an optional **Praxis / Clinic name** field. If you fill it in, the name appears at the top of the cover page above the patient block — handy when you generate one report for your GP and another for your cardiologist. The field is remembered as a per-account preference so the next report pre-fills with whatever you used last; clear it to omit the line entirely.

:::tip
For doctor appointments, generate the report covering the period since the last visit. Most physicians prefer a 3-month or 6-month overview — the 90-day default fits the common case in one click.
:::

## Report Contents

### Vital Signs Summary

The report includes a summary of key vital signs for the selected period:

| Metric | Details |
|--------|---------|
| Weight | Average, min, max, trend direction |
| BMI | Current value, classification per WHO (DEGAM age-adjusted bands for 65+) |
| Blood Pressure | Average Sys/Dia, [hypertension](https://en.wikipedia.org/wiki/Hypertension) classification per [ESH](https://www.eshonline.org/) 2023 |
| Pulse / Heart Rate | Average, min, max |
| Blood Glucose | Per-context averages (fasting / postprandial / random / bedtime), distribution, time-in-range when available ([ADA](https://diabetes.org/) ranges) |
| Oxygen Saturation | Average, min, with personalised thresholds for COPD baselines (BTS / [NICE NG115](https://www.nice.org.uk/guidance/ng115)) |
| Body Composition | Body fat %, total body water (kg), bone mass (kg) — labelled as bioimpedance estimates, not DEXA-comparable |

:::note
If you have set custom thresholds under **Settings → Health Targets**, the report prints both your custom target and the standard guideline value side by side, with a clear "custom range applied" badge.
:::

### Blood Pressure Classification

Readings are classified according to the ESH 2023 guidelines (numeric thresholds unchanged from 2018; ESC has since withdrawn from the joint document):

| Category | Systolic (mmHg) | Diastolic (mmHg) |
|----------|-----------------|-------------------|
| Optimal | < 120 | < 80 |
| Normal | 120--129 | 80--84 |
| High Normal | 130--139 | 85--89 |
| Grade 1 Hypertension | 140--159 | 90--99 |
| Grade 2 Hypertension | 160--179 | 100--109 |
| Grade 3 Hypertension | >= 180 | >= 110 |

### BMI Classification

BMI values are classified per WHO standards:

| Category | BMI Range |
|----------|-----------|
| Underweight | < 18.5 |
| Normal weight | 18.5--24.9 |
| Overweight | 25.0--29.9 |
| Obesity Class I | 30.0--34.9 |
| Obesity Class II | 35.0--39.9 |
| Obesity Class III | >= 40.0 |

### Medication Compliance

For each active medication, the report shows:

- Medication name, dosage, and schedule
- **Compliance rate** -- the [adherence](https://en.wikipedia.org/wiki/Adherence_(medicine)) figure: percentage of scheduled intakes that were confirmed (taken) during the report period
- Missed and skipped intakes count

### Mood Distribution

If mood tracking data is available for the report period, a summary is included:

- Distribution across the 5-point scale (percentage per level)
- Average mood value
- Number of entries

### Optional AI Analysis

When AI insights are enabled, the report can include an AI-generated summary:

- Trend interpretation for vital signs
- Notable patterns or anomalies
- General health observations

:::caution
The AI analysis is informational only and does not constitute medical advice. The report includes a disclaimer footer stating this explicitly.
:::

## Format and Language

- **Format**: A4 PDF, structured with headers and tables
- **Language**: Follows your selected UI locale (English or German). Numbers, dates, and units (mg/dL vs mmol/L, kg, mmHg) format per locale via the same `useFormatters()` helper that powers the dashboard.
- **Disclaimer**: A footer on each page notes that the report is auto-generated and does not replace professional medical assessment

:::caution
The PDF is generated entirely in the browser using jsPDF. For very large datasets (thousands of readings), generation may take a few seconds. Some older or mobile browsers may have limited support for client-side PDF generation.
:::
