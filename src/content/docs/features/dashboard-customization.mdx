The dashboard ships with a sensible default layout, but the right order depends on what you actually track. If you don't take medication, the compliance widget is noise. If glucose is your daily focus, it should be the first thing you see. HealthLog lets you show/hide and reorder every widget on the dashboard.

## Customize the Layout

1. Open the dashboard and tap the **Customize** icon in the top right (or **Settings → Dashboard**). Personal target values (BP, BMI, glucose, pulse) live in their own section at **Settings → Health Targets**.
2. Toggle widgets on or off with the visibility switch.
3. Drag the handle on the left of each widget to reorder.
4. Save. Your layout persists per device and per user.

Available widgets:

- Quick Add buttons
- Weight summary
- Blood pressure summary
- Glucose summary
- Pulse summary
- BMI card
- Mood snapshot
- Medication compliance
- Today's reminders
- Recent achievements card (v1.4.15+)
- AI Insight cards (per metric)

### Tile and chart toggles, separately (v1.4.15+)

Each metric on the dashboard appears twice: as a small **tile** in the top strip (single number, trend chip) and as a fuller **chart** in the row below. As of v1.4.15 those two surfaces have separate visibility switches in the layout settings — the row header reads "Tile / Chart" (EN) or "Kachel / Chart" (DE).

So if you want to see a tile for blood pressure but not the chart, you can. Existing saved layouts keep behaving as before — one switch controls both surfaces — until you flip the new toggle for that metric.

## Reset to Defaults

The Customize panel has a **Reset to defaults** button. It restores the original order and visibility for every widget, but it doesn't delete any data — it only clears the layout preference.

:::tip
If you only want to hide the AI Insight cards (e.g., you haven't configured a provider yet), toggle them off here rather than disabling AI globally. The provider stays configured for the Doctor Report PDF.
:::

## Mobile vs. Desktop

The layout is shared across breakpoints. Widgets you hide on desktop are also hidden on mobile. The order is the same, but the grid collapses to a single column on small screens.

The dashboard's measurement-tile strip uses a true CSS Grid track with a 9 rem floor per tile (v1.4.5+). Every tile takes the same share of the row; on narrow viewports the row wraps rather than triggering a horizontal scroll. The chart strip below the tiles auto-buckets its data on long ranges (v1.4.6) — daily for ≤ 90 days, weekly mean for 91–730 days, monthly mean beyond — with an inline chip showing which bucket is active. The mood chart now follows the same thresholds (v1.4.15+) so a long history of daily mood entries no longer paints a noisy spaghetti line — you see weekly means past 90 days, monthly means past 730.

### 7-day trend on every tile (v1.4.15+)

Every metric tile in the top strip shows a coloured `(±N.N)` next to the value. That delta is the 7-day trend: the average of the last 7 days minus the average of the 7 days before that, in the metric's own units. The label below the value reads "7d trend" (EN) / "7T-Trend" (DE) instead of the previous "7d average". The colour follows what's good for that metric — green for "up is good" (steps, sleep), orange for "up is concerning" (BP, BMI), muted for "neutral" (weight). One glance tells you which way the metric is moving.

Once you finish the onboarding checklist, the dashboard stops re-fetching the checklist gates on every load (v1.4.14+) — opening the dashboard is roughly a second faster for established accounts because two background requests no longer fire. Insights chart bundles also load on demand on the **Insights** page, so the first paint is faster for everyone.

## What's Not Customizable

- The top navigation bar
- The sidebar (collapsible, but not reorderable)
- The Quick Add menu items (driven by which metrics you actively log)

Those are intentional — they're navigation, not content.
