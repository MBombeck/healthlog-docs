HealthLog tracks and analyzes key health metrics, including weight, [blood pressure](https://en.wikipedia.org/wiki/Blood_pressure), heart rate, [body composition](https://en.wikipedia.org/wiki/Body_composition), sleep, activity, and [blood glucose](https://en.wikipedia.org/wiki/Blood_sugar_level). All metrics can be entered manually or synced automatically via integrations (e.g., Withings), and are displayed as trend visualizations.

## Supported Metrics

| Metric | Unit | Automatic Analysis | Withings Sync |
|--------|------|-------------------|----|
| Weight | kg | [BMI](https://en.wikipedia.org/wiki/Body_mass_index) calculation, trend analysis | Yes |
| [Blood Pressure](https://en.wikipedia.org/wiki/Blood_pressure) (Sys/Dia) | mmHg | [ESH](https://www.eshonline.org/) 2023 classification | Yes (BPM Connect) |
| [Heart Rate](https://en.wikipedia.org/wiki/Heart_rate) | bpm | Trend analysis | Yes |
| Body Fat Percentage | % | [ACE](https://www.acefitness.org/) bands (essential / athlete / fitness / acceptable / overweight / obese) | Yes |
| Total Body Water | kg | Trend analysis (Watson formula reference) | Yes (Body+ scales) |
| Bone Mass | kg | Trend analysis | Yes (Body+ scales) |
| [Sleep](https://en.wikipedia.org/wiki/Sleep) Duration | hours | [AASM](https://aasm.org/) 2015 adult range | — |
| [Sleep Stages](https://en.wikipedia.org/wiki/Sleep_cycle) (awake / REM / core / deep) | minutes | Per-stage breakdown when the source reports it | — |
| Activity (Steps) | steps | Saint-Maurice JAMA 2020 (continued benefit through ~12 000/d) | Yes |
| [Blood Glucose](https://en.wikipedia.org/wiki/Blood_sugar_level) | mg/dL or mmol/L | Per-context ranges ([ADA](https://diabetes.org/) 2024) — fasting / postprandial / random / bedtime | — |
| [Oxygen Saturation](https://en.wikipedia.org/wiki/Pulse_oximetry) (SpO2) | % | BTS / [NICE NG115](https://www.nice.org.uk/guidance/ng115); personalised baseline for COPD | Yes (ScanWatch) |

The table above lists the metrics with their own clinical analysis. Beyond them, HealthLog charts **every metric the iOS client can read from Apple Health**: resting heart rate, [heart-rate variability](https://en.wikipedia.org/wiki/Heart_rate_variability), [VO₂max](https://en.wikipedia.org/wiki/VO2_max), respiratory rate, active energy, flights climbed, walking/running distance, the walking-quality family (speed, step length, asymmetry, double support, steadiness), the body-composition family (lean/fat/fat-free/muscle mass, BMI), environmental and headphone [audio exposure](https://en.wikipedia.org/wiki/Health_effects_from_noise), time in daylight, and — where a connected sleep or breathing device reports it — the [apnea–hypopnea index (AHI)](https://en.wikipedia.org/wiki/Apnea%E2%80%93hypopnea_index), the count of breathing disruptions per hour of sleep used to grade sleep apnea, and more. Each gets its own chart surface. See the [measurements API type table](/api/measurements/#measurement-types) for the full machine-readable list.

All metrics are stored canonically in **SI** units — matching what Withings devices report and what Health Connect's records provide. A per-user **metric/imperial display preference** (Settings → Display) drives a render-time transform only: walking speed reads in km/h, distance in km, and imperial converts at display time. Stored and exported values stay SI, so a Doctor Report or [FHIR R4 export](/features/export-import/#health-record-export-pdf--fhir-r4) always carries canonical units. Anyone with a Withings connection sees the supported metrics flowing in automatically on the next sync, no extra config.

:::tip
Reference ranges for any metric can be overridden under **Settings → Health Targets**. The dashboard, traffic-light indicators, charts, and the Doctor Report PDF all switch to your custom value, and the report prints both your custom target and the standard guideline value side by side.
:::

## Data Entry

### Single Entry

Individual readings can be logged directly from the dashboard. Each entry is automatically timestamped.

### Batch Entry

A batch mode is available for backfilling multiple readings at once — useful for transferring data from a paper diary or another tracking system.

## Trend Analysis

All metrics are analyzed across three time ranges:

- **7 days** -- Short-term trends
- **30 days** -- Monthly trends
- **90 days** -- Long-term development

Visualizations are rendered with Recharts (line and bar charts). Long ranges (>90 days) auto-bucket the data — weekly mean for 91–730 days, monthly mean beyond — with an inline chip showing the active bucket so the aggregation is never silent.

A **comparison overlay** lets you toggle "vs. last month" / "vs. last year" from the `/insights` hero — the prior period renders as a dimmed line beneath the current one, with a delta callout (Δ ±N) next to the headline value. See [Comparison views](/dashboard/comparison/) for the full toggle UX.

## BMI Calculation

BMI is calculated automatically from weight and height. Height is set once in the user profile.

```
BMI = weight / (height_m * height_m)
```

:::note
Height must be configured in your user profile for automatic BMI calculation to work.
:::

## Blood Pressure Classification

Readings are classified according to the ESH 2023 hypertension guidelines (ESC withdrew from the joint authoring; the numeric thresholds are unchanged from 2018):

| Category | Systolic (mmHg) | Diastolic (mmHg) |
|----------|-----------------|-------------------|
| Optimal | < 120 | < 80 |
| Normal | 120--129 | 80--84 |
| High Normal | 130--139 | 85--89 |
| Grade 1 Hypertension | 140--159 | 90--99 |
| Grade 2 Hypertension | 160--179 | 100--109 |
| Grade 3 Hypertension | >= 180 | >= 110 |

:::tip
Classification is based on the higher value. If systolic and diastolic fall into different categories, the higher grade applies.
:::

## Charts and Visualizations

All charts are built with Recharts and include the following types:

- **Line charts** for weight, BMI, and heart rate
- **Dual-line charts** for blood pressure (Sys/Dia)
- **Bar charts** for steps and sleep duration
- Color coding by classification level for blood pressure

## Doctor's Report (PDF Export)

HealthLog generates a structured PDF report for doctor visits.

- **Format**: PDF via jsPDF (generated client-side)
- **Content**: Blood pressure history, weight trends, BMI, glucose, oxygen saturation, body composition, medication compliance, mood
- **Classification**: ESH 2023 (BP), WHO + DEGAM age-adjusted (BMI), ADA 2024 (glucose), BTS / NICE NG115 (SpO2)
- **Time range**: Freely selectable

:::caution
The PDF is generated entirely in the browser. For very large datasets, generation may take a few seconds.
:::
