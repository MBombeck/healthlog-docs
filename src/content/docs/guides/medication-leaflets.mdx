Every medication has an official leaflet: the patient information that comes
in the pack, published by the national medicine registry of the country it is
sold in. HealthLog helps you find it and keeps the link with the medication.
It does not download, store or read the leaflet.

## Find a leaflet

Open a medication and look for **Leaflet** on its overview. **Find leaflet**
opens the official registry search of the country you picked, in a new tab,
with the medication's name already searched for. The Belgian and Australian
registries also take the strength ("Ramipril 5 mg"); the others search by
name, because the strength is a separate field there.

Three registries do not take a search from a link at all: Germany's AMIce,
Health Canada's Drug Product Database and the European Medicines Agency. For
those the search page opens empty, and HealthLog tells you which name to type
into it.

The same links are on the medication card's menu.

The leaflet comes from the national registry, not from HealthLog. Check that
the product you open matches your medication's name, strength and form: many
medicines have similar names, and one name can cover several strengths.

| Registry | Opens | Search filled in |
| --- | --- | --- |
| Poland | Rejestr Produktów Leczniczych | name |
| Germany | BfArM AMIce | no, type the name |
| Spain | AEMPS CIMA | name |
| France | Base de données publique des médicaments | name |
| United Kingdom | MHRA Products | name |
| Belgium | FAMHP medicines database | name and strength |
| Netherlands | CBG Geneesmiddeleninformatiebank | name |
| United States | DailyMed | name |
| Canada | Health Canada Drug Product Database | no, type the name |
| Australia | TGA ARTG | name and strength |
| Brazil | ANVISA Bulário Eletrônico | name, then press **Consultar** |
| European Union | European Medicines Agency | no, type the name |

## Nothing leaves the server

HealthLog's server makes no request to any registry. The link is built from a
fixed list of registry search addresses, and your browser opens it the same
way it opens any other link. The registry sees an ordinary visit from your
browser, with the medication name in the address, as if you had typed the
name into its search box yourself. No firewall or Content Security Policy
change is needed on your instance.

## Pick the country

Choose a **Medicine registry** right in the medication's **Leaflet** section
while none is set, or later under **Settings > Modules > Medications**. Pick
**None** to hide the search.

The registry is independent of the app's language: someone reading HealthLog
in English in Warsaw picks Poland. The first time you open HealthLog after
the update, it picks one for you only where your language and your time zone
agree on a country (German in Berlin is Germany, Polish anywhere is Poland);
otherwise it starts at **None**. After that it only changes when you change
it.

## Save the leaflet link

When you have found the right leaflet, copy its address from the registry and
keep it with the medication:

- on the medication's overview, under **Leaflet**, choose **Save a leaflet
  link**, paste the address and save; or
- edit the medication and paste it into **Leaflet link** on the last step.

Only `https://` addresses are accepted. The saved link shows as **Official
leaflet** and opens in a new tab; **Edit link** changes it and **Remove link**
clears it. The link travels with your backups, restores and data export.
