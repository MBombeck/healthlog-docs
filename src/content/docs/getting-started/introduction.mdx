## What is HealthLog?

HealthLog is a **self-hosted, mobile-first Progressive Web App** (PWA) for comprehensive health tracking. It combines manual vital sign logging with automatic device syncing, smart medication management, and AI-powered insights.

All your data stays on your own infrastructure — no cloud lock-in, no subscriptions, full control. HealthLog is free software under the [GNU AGPL-3.0](https://www.gnu.org/licenses/agpl-3.0.en.html): you can run, study, modify, and redistribute it, and anyone you offer it to over a network is entitled to the source.

## Key Features

- **Vital Sign Tracking** — Weight, blood pressure, heart rate, body fat, sleep, activity, mood, blood glucose, oxygen saturation, total body water, bone mass — plus the full set of HealthKit metrics (HRV, VO₂max, resting heart rate, respiratory rate, the walking-quality and body-composition families, audio exposure, and more)
- **Medication Management** — Flexible recurrence (daily, weekday subsets, bi-weekly, rolling, RRULE, one-time, as-needed, cyclic on/off weeks), route of administration with injection-site tracking, and cadence-aware compliance analytics
- **Automated Reminders** — Telegram, ntfy, Web Push notifications
- **Withings Sync** — Automatic import from smart scales, BP monitors, ScanWatch (SpO2), and Body+ (TBW, bone mass)
- **AI Insights** — Multi-provider (OpenAI / Anthropic Claude / ChatGPT subscription via Codex / local OpenAI-compatible), inline charts in findings, three years of context per metric. The ChatGPT path uses a one-click device-code flow against `auth.openai.com` — no API plan, no separate billing
- **Health-Record Export** — A doctor handover as an enriched PDF and a machine-readable [HL7 FHIR R4](https://hl7.org/fhir/R4/) bundle (LOINC-coded, UCUM units), with selectable date range and per-domain sections and an optional AI summary
- **First-Paint Dashboard** — Above-the-fold tiles assemble in one snapshot round-trip; the daily briefing and insight are pre-generated overnight so nothing blocks on the model
- **Custom Health Targets** — Override any guideline default with the values your clinician set, audit-logged
- **Customizable Dashboard** — Show / hide / reorder every widget
- **Built-in Feedback** — Bug, feature, question, or other — with optional GitHub escalation for admins
- **Native iOS App** — A SwiftUI client in public beta via TestFlight with live Apple Health (HealthKit) two-way sync, local medication reminders, and passkey sign-in. See the [iOS app](/ios/ios-app/) guide
- **Native API Clients** — Bearer-token + refresh-token flow, Idempotency-Key header support — ready for the iOS app and external automation (n8n, Health Connect)
- **Gamification** — 59 persistent achievements (six of them hidden Easter-egg badges) to reward consistent tracking
- **Passkey Authentication** — Passwordless login via WebAuthn
- **Dark-only Dracula Theme** — Easy on the eyes at any time of day

## Tech Stack

| Component | Technology |
|---|---|
| Framework | Next.js 16 (App Router, React Server Components) |
| Language | TypeScript (strict mode) |
| Database | PostgreSQL 16 |
| ORM | Prisma 7 with PrismaPg Adapter |
| Styling | Tailwind CSS 4 + shadcn/ui (Dracula Theme) |
| Client State | TanStack Query 5 |
| Auth | SimpleWebAuthn v13 (Passkeys) + session-based |
| Background Jobs | pg-boss v12 |
| Containerization | Docker + Docker Compose |

## Requirements

To run HealthLog, you need the following:

- **Docker** and **Docker Compose** (v2+)
- A **reverse proxy with HTTPS** (e.g., Nginx Proxy Manager, Traefik, Caddy)
- **PostgreSQL 16** (included in the bundled `docker-compose.yml`)
- A **domain with a valid SSL certificate** (Passkeys require HTTPS)

:::caution
Passkeys only work over HTTPS. Running HealthLog without a valid SSL certificate is not supported.
:::
